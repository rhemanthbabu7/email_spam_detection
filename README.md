# Email Spam Detection using Naive Bayes

## Project Overview

This project detects whether an email message is **Spam** or **Not Spam (Ham)** using **Machine Learning** and **Natural Language Processing (NLP)** techniques.

The model is trained using the **Naive Bayes Classification Algorithm**, which is commonly used for text classification problems.

The project performs:

* Email text preprocessing
* Feature extraction using text vectorization
* Training a Naive Bayes model
* Spam prediction
* Model accuracy evaluation
* Data visualization

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Natural Language Processing (NLP)

---

## Dataset Information

The dataset contains email or SMS text messages categorized into:

### Labels

* **Spam** → Unwanted or promotional messages
* **Ham** → Legitimate messages
---

## Machine Learning Workflow

1. Load dataset using Pandas
2. Clean and preprocess text data
3. Convert text into numerical features using vectorization
4. Split dataset into training and testing data
5. Train model using Naive Bayes algorithm
6. Predict spam or ham messages
7. Evaluate model accuracy
8. Visualize dataset information

---

## Algorithm Used

### Naive Bayes Classifier

Naive Bayes is a supervised machine learning algorithm mainly used for **text classification** problems.

It works using probability and assumes that features are independent.

Why used in this project:

* Fast and efficient
* Works well for text classification
* Good performance for spam detection
* Simple and easy to implement
